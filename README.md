# ABTalks Redesign

A mobile-first redesign of ABTalks, a 60-day coding challenge platform for college students.

## Quick Start

```bash
cd landing-page
npm install
npm run dev
```

Open **http://localhost:5173** at **390px width** for the intended mobile experience.
